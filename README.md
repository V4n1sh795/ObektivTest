# API Service
	
Сервис для отслеживания цен на квартиры с сайта `prinzip.su` и отправки уведомлений об изменении цены на email.

## Описание

API позволяет:
- Подписаться на отслеживание квартиры по ссылке
- Получить текущие цены на все отслеживаемые квартиры
- Вручную обновить цену квартиры

## Технологии

- **ASP.NET Core 10.0**
- **Entity Framework Core** (SQLite)
- **HtmlAgilityPack** (парсинг HTML)
- **MailKit** (отправка email уведомлений)
- **Docker**

## Запуск

### Через Docker Compose

```bash
docker-compose up --build
```

Сервис будет доступен на порту `8080`.

### Переменные окружения

Для работы email уведомлений создайте файл `.env` в директории `apiservice/`:

```env
EMAIL=your@gmail.com
APP_PASSWD=1111 1111 1111 1111
```

Где `APP_PASSWD` — пароль приложения Gmail для внешней авторизации.

## Эндпоинты

### 1. Получить список всех квартир

**GET** `/`

Возвращает список всех отслеживаемых квартир из базы данных.

**Ответ:**
```json
[
  {
    "id": 1234567890,
    "link": "https://prinzip.su/flats/...",
    "label": "...",
    "place": "...",
    "prices": [...],
    "emails": ["user@example.com"]
  }
]
```

---

### 2. Подписаться на отслеживание квартиры

**POST** `/api/flat`

Добавляет квартиру в список отслеживаемых. Если квартира уже существует, добавляет email к существующей подписке.

**Тело запроса:**
```json
{
  "link": "https://prinzip.su/flats/...",
  "email": "user@example.com"
}
```

**Параметры:**
| Параметр | Тип   | Обязательный | Описание                                      |
|----------|-------|--------------|-----------------------------------------------|
| link     | string| Да           | Ссылка на квартиру (только домен prinsip.su)  |
| email    | string| Да           | Email для получения уведомлений               |

**Валидация:**
- Email должен быть корректного формата
- Ссылка должна быть HTTPS и вести на домен `prinzip.su` или `www.prinzip.su`
- Путь ссылки должен начинаться с `/flats/`

**Ответ:**
- `200 OK` — успешно
- `400 Bad Request` — некорректный email или ссылка

**Пример:**
```bash
curl -X POST http://localhost:8080/api/flat \
  -H "Content-Type: application/json" \
  -d '{"link": "https://prinzip.su/flats/shartashpark/65045/", "email": "user@example.com"}'
```

---

### 3. Получить цены на все квартиры

**GET** `/api/prices`

Возвращает информацию по всем отслеживаемым квартирам с их последней ценой.

**Ответ:**
```json
[
  {
    "id": 1234567890,
    "link": "https://prinzip.su/flats/...",
    "label": "Название квартиры",
    "place": "Адрес квартиры",
    "lastPrice": {
      "amount": 5000000,
      "date": "2025-08-08T12:00:00Z"
    },
    "emails": ["user@example.com"]
  }
]
```

**Поля ответа:**
| Поле        | Тип     | Описание                              |
|-------------|---------|---------------------------------------|
| id          | ulong   | Уникальный идентификатор квартиры     |
| link        | string  | Ссылка на квартиру                  |
| label       | string  | Название/описание квартиры           |
| place       | string  | Местоположение квартиры              |
| lastPrice   | object  | Последняя цена                      |
| lastPrice.amount | decimal | Сумма в рублях                 |
| lastPrice.date   | DateTime | Дата последнего обновления    |
| emails      | array   | Список email для уведомлений         |

**Пример:**
```bash
curl http://localhost:8080/api/prices
```

---

### 4. Обновить цену квартиры

**PATCH** `/api/patch_price`

Вручную обновляет цену квартиры и отправляет уведомления всем подписчикам.

**Тело запроса:**
```json
{
  "link": "https://prinzip.su/flats/...",
  "new_price": "5 000 000"
}
```

**Параметры:**
| Параметр  | Тип   | Обязательный | Описание                          |
|-----------|-------|--------------|-----------------------------------|
| link      | string| Да           | Ссылка на квартиру                |
| new_price | string| Да           | Новая цена (строка с цифрами)     |

**Ответ:**
- `200 OK` — успешно
- `400 Bad Request` — квартира не найдена или некорректная ссылка

**Пример:**
```bash
curl -X PATCH http://localhost:8080/api/patch_price \
  -H "Content-Type: application/json" \
  -d '{"link": "https://prinzip.su/flats/123", "new_price": "4 500 000"}'
```

## Структура базы данных

### Таблица `Flats`
| Поле    | Тип     | Описание                    |
|---------|---------|-----------------------------|
| Id      | ulong   | Первичный ключ (XXHash64)   |
| link    | string  | Ссылка на квартиру          |
| label   | string  | Название квартиры           |
| place   | string  | Адрес/местоположение        |
| Emails  | list    | Список email подписчиков    |

### Таблица `Prices`
| Поле        | Тип      | Описание                     |
|-------------|----------|------------------------------|
| Id          | int      | Первичный ключ               |
| price       | int      | Цена в рублях                |
| TimeChanged | DateTime | Дата изменения цены          |
| FlatId      | ulong    | Внешний ключ на таблицу Flats|

## Как это работает

1. При отправке POST запроса на `/api/flat` сервис:
   - Проверяет валидность email и ссылки
   - Парсит страницу квартиры (цена, название, адрес)
   - Сохраняет данные в базу
   - При повторной подписке добавляет email к существующей квартире

2. При обновлении цены (PATCH `/api/patch_price`):
   - Проверяет существование квартиры
   - Добавляет новую запись о цене
   - Отправляет email уведомления всем подписчикам

3. Email уведомления отправляются через Gmail SMTP
